# 🚀 AgriVision AI - Quick Start Guide

## Instant Demo (30 seconds)

1. **Open** `index.html` in any browser (Chrome, Firefox, Edge, Safari)
2. **Click** "Tomato Spot" sample image (red tomato emoji 🍅)
3. **Wait** 3 seconds for AI scanning animation
4. **See** instant disease diagnosis with treatment plan
5. **Done!** You just demonstrated AI-powered plant disease detection

---

## Full Feature Tour (3 minutes)

### Tab 1: AI Diagnostic Hub 🔬
- **Try**: Click any of the 3 sample images below the upload box
  - 🍅 Tomato Spot → Bacterial disease detection
  - 🌾 Rice Blast → Fungal disease detection  
  - ✅ Healthy Leaf → No disease found
- **Watch**: 3-second scanning animation
- **Result**: Disease name, confidence score, treatment steps, recovery time

### Tab 2: Regional Analytics 📊
- **Click**: "Regional Analytics" tab in header
- **See**: Loading skeletons → smooth chart reveal
- **Charts**: 
  - Line graph: 4-week disease spread trend
  - Pie chart: Crop distribution
  - Risk cards: Temperature, humidity, rainfall alerts

### Tab 3: Local Resources 🗺️
- **Click**: "Local Resources" tab
- **Interactive Map**: Click any pin (🏪 ❄️ 🔬) on the map
- **See**: Map zooms smoothly to location
- **Sidebar**: Shows phone, stock status, distance, address

### Tab 4: Yield Optimizer 💰
- **Click**: "Yield Optimizer" tab
- **Enter**:
  - Acreage: `5`
  - Crop: `Tomato` (from dropdown)
  - Season: Any option
- **Click**: "📊 Calculate Profit" button
- **See**: Animated ROI bar, profit projection, recommendations

## Common Issues & Fixes

### Map not loading?
- **Cause**: No internet connection
- **Fix**: Check WiFi/data, refresh page

### Charts not appearing?
- **Cause**: Chart.js CDN blocked
- **Fix**: Refresh page, check firewall

### Webcam not working?
- **Cause**: Browser permission denied
- **Fix**: Use sample images instead (better for demo anyway!)

### Mobile menu not showing?
- **Cause**: Browser width > 768px
- **Fix**: Resize window smaller or use actual mobile device
