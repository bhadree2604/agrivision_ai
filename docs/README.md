# 🌿 AgriVision AI

A modern, professional single-page dashboard web application for rural farmers and agricultural officers in Namakkal and Rasipuram, Tamil Nadu.

## 🎯 Demo-Ready Features (Live Judging Optimized)

### Quick Demo Flow
1. **Open** `index.html` in any browser
2. **Click** one of the 3 sample leaf images (Tomato Spot, Rice Blast, Healthy Leaf) for instant AI analysis
3. **Switch tabs** to see Regional Analytics with animated charts
4. **Click map pins** to view resource center details with smooth zoom
5. **Toggle language** English ⇄ Tamil to see complete translation
6. **Try dark mode** for visual variety
7. **Test mobile** by scanning QR code on phone

## Features

### 🔬 AI Diagnostic Hub
- **Image Upload**: Drag-and-drop or click to upload plant leaf photos
- **Webcam Integration**: Capture photos directly from your device camera
- **Quick Demo Samples**: 3 pre-loaded images for instant demonstration
- **AI Scanning Animation**: 3-second animated scanning matrix overlay
- **Disease Detection Results**: Shows disease name, confidence score, severity index, and treatment protocol
- **Recovery Timeline**: Estimated recovery time for detected diseases
- **Bilingual Treatment Steps**: Full Tamil translation available

### 📊 Regional Outbreak Analytics
- **Disease Spread Chart**: Line chart tracking disease cases over the last 4 weeks
- **Affected Crops**: Pie chart showing distribution of affected crop types
- **Risk Index Widget**: Color-coded risk assessment based on humidity, temperature, and rainfall data
- **Real-time Alerts**: Warning notifications for high-risk conditions
- **Loading Skeletons**: Professional pulse animations while charts load
- **Translated Labels**: Chart labels in English and Tamil

### 🗺️ Hyper-Local Resources Network
- **Interactive Map**: Centered on Rasipuram/Namakkal with location pins
- **Resource Centers**: Supply centers, cold storages, and soil-testing labs marked with icons
- **Detail Sidebar**: Click any pin to view phone number, stock status, distance, and address
- **Smooth Zoom**: Animated map transitions when selecting locations
- **Highlight Animation**: Sidebar pulses when location is selected

### 💰 Yield & Profit Optimizer
- **Input Form**: Enter acreage, crop type, and season
- **Input Validation**: Prevents invalid calculations with inline feedback
- **ROI Calculator**: Animated progress bar showing return on investment
- **Cost Analysis**: Breakdown of market price, fertilizer costs, and net profit
- **Smart Recommendations**: AI-powered suggestions to maximize profit (in both languages)

## Getting Started

Simply open `index.html` in your web browser. No server or installation required!

### Browser Requirements
- Modern browser with JavaScript enabled
- Camera access for webcam feature (optional - use sample images instead)
- Internet connection for map tiles

### Demo Tips for Judges
1. Start with AI Diagnostic tab - click a sample image
2. Wait for 3-second AI scanning animation
3. Toggle language to show Tamil translation
4. Switch to Analytics tab to see loading skeletons → charts
5. Go to Resources tab, click map pins for zoom effect
6. Try Yield Optimizer with validation (enter 0 to see error)
7. Toggle dark mode for visual variety
8. Open on mobile via QR code to show responsiveness
